How it works: This extension intercepts the /console/tb/creds API response when the AWS Console fetches temporary credentials. Credentials are captured automatically when you navigate to or refresh the AWS Console.
Waiting for credentials...

The extension intercepts credentials when AWS Console requests them. To trigger this:

1. Make sure you're logged into the AWS Console
2. Navigate to any AWS Console page
3. If needed, refresh the page (F5)

Credentials will appear here automatically once captured.
Not on AWS Console

This extension only works on AWS Console pages. Please navigate to console.aws.amazon.com and ensure you're logged in.
